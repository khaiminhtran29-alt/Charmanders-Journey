# Charmander's Journey

Charmander's Journey is a GUI game implemented with Java Swing where you follow  on his journey home. Help him get home by building a team of Pokemon and battling trainers until you are strong enough to battle the Champion to earn a special skill that enables Charmander to fly home.

Concepts Used: 
 - Java Swing
 - Enum
 - Inheritance
 - Exception handling (IOException)
 - File reading
 - Functional Interface
